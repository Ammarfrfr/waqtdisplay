# WaqtDisplay

Android app for prayer and Jamaat times, LED display sync, and masjid announcements.

## Download

- [WaqtDisplay-v1.0.0.apk](./WaqtDisplay-v1.0.0.apk)
- Landing page: https://waqtdisplay.vercel.app
- API: https://waqtdisplay.onrender.com

## Install

1. Download the APK.
2. Allow install from your browser.
3. Open and sign in.

The source code is maintained in a separate private repository.
